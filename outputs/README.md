# Restored Test Outputs

This directory will contain the model's restored outputs on the test set.

Generated by running:
```bash
python evaluate.py \
    --input_dir /path/to/test_noisyLR/NoisyLR \
    --output_dir ./outputs
```

Each output file:
- `<stem>.npy` — float32 array, shape (256, 256), range [0, 1]
- `<stem>.png` — 8-bit PNG for visual inspection
- `metrics.json` — PSNR, SSIM, LPIPS, inference timing
