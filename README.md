# KLA Image Restoration — NAFNet-SR

AI-based restoration of degraded semiconductor inspection images.
Handles speckle noise, Gaussian noise, and 2× super-resolution in a single forward pass.

**Model**: NAFNet-SR (Nonlinear Activation Free Network + PixelShuffle SR head)  
**Input**: 128×128 NoisyLR `.npy` arrays (float32, may exceed [0,1])  
**Output**: 256×256 Restored `.npy` arrays (float32, range [0,1])

---

## Inference (evaluate.py)

```bash
# Basic inference (test set, no GT):
python evaluate.py \
    --input_dir /path/to/NoisyLR \
    --output_dir ./outputs

# With GT metrics (val set):
python evaluate.py \
    --input_dir /path/to/NoisyLR \
    --output_dir ./outputs \
    --gt_dir /path/to/GT

# With Test-Time Augmentation (slightly better quality, slower):
python evaluate.py \
    --input_dir /path/to/NoisyLR \
    --output_dir ./outputs \
    --tta

# All options:
python evaluate.py --help
```

**Output files:**
- `outputs/<stem>.npy` — restored array, shape (256,256), float32, range [0,1]
- `outputs/<stem>.png` — 8-bit PNG for visual inspection
- `outputs/metrics.json` — PSNR/SSIM/LPIPS + inference timing

## Architecture

**NAFNet-SR**: U-Net encoder-decoder with NAFBlocks + PixelShuffle 2× SR head.

```
NoisyLR (128×128) → Stem → Encoder (4 scales) → Bottleneck → Decoder → SR Head → Restored (256×256)
```

- **NAFBlock**: SimpleGate (replaces all activations) + depthwise conv + LayerNorm
- **SimpleGate**: splits channels, element-wise multiply — no ReLU/GELU
- **SR Head**: Conv → PixelShuffle(×2) → Conv — outputs full-resolution image
- **Residual**: bilinear upsampled input added to SR head output

**Loss Function**: `L = 1.0·Charbonnier + 0.1·FreqFFT + 0.2·SSIM + 0.1·SobelEdge`

| Loss | Purpose |
|------|---------|
| Charbonnier | Robust pixel reconstruction (handles speckle outliers) |
| FreqFFT | Penalises missing high-frequency edge detail in Fourier domain |
| SSIM | Structural / perceptual quality |
| SobelEdge | Preserves semiconductor feature boundary sharpness |

---

## Dataset Notes

- GT is always in [0, 1] range
- NoisyLR **can go slightly negative** (-0.003) AND exceed 1.0 (up to ~1.54)
- ~99% of NoisyLR files have speckle overflow (max > 1.0) — this is expected
- Pre-processing: NoisyLR is clipped to [-0.05, 2.0] then rescaled to [0, 1]
